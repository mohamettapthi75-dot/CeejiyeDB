# CeejiyeDB v2.0 Roadmap 🚀

## Core Database Features
- [x] **MUDDAD** command (TTL / key expiration)
- [x] **KOOB** command (increment integer values)
- [x] **DHIMIS** command (decrement integer values)
- [ ] Bulk operations (KAYDI_BADAN, SOOQAAD_BADAN)
- [ ] Backup command
- [ ] Restore command
- [ ] Export JSON
- [ ] Import JSON
- [x] Database statistics command (**XAALAD**)

## Data Types

- [x] Integers
- [x] Lists
- [ ] Floats
- [x] Sets
- [x] Hashes (dictionary/object storage)
- [ ] Nested JSON objects
